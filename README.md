# Business ML Pipeline

An end-to-end Machine Learning pipeline for solving a business problem using **Customer Churn Prediction**.

## Features

* Business problem definition
* Synthetic customer data generation
* Data preprocessing
* Feature transformation
* Train-test split
* Logistic Regression model
* Model evaluation
* Churn prediction
* Business-focused insights

## Dataset

The project uses customer information such as demographics, purchase behavior, website activity, support tickets, and churn status.

## Model

**Logistic Regression** is used for binary customer churn classification.

## Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Classification Report

## Business Use

The predicted churn risk can support targeted retention campaigns, CRM integration, and proactive customer engagement.

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Joblib
* Google Colab / Jupyter Notebook

## File

`Machine_learnig_pipeline.ipynb`

## Purpose

This project demonstrates how Machine Learning can transform customer data into predictions that support business decision-making and actionable insights.
